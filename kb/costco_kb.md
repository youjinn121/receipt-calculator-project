# Costco KB

## 1. 상품 상세 구조
- 상품명 라인과 상품 상세 라인이 분리됨
- 상품 상세 라인: 상품코드, 수량, 단가, 금액 순

## 2. 주요 할인 표기
- CPN
- IRC
- EXM
- PP

## 3. 상품 단위 할인 처리
- discount_target 또는 discount_detail을 활용하여 상품에 연결
- 명시 대상이 없는 경우 최근 생성 item에 귀속

## 4. 영수증 단위 정보
- 상품수 소계
- Sub-총상품수
- 합계

## 5. 최종 금액 기준
- 합계

## 6. Validation 활용
- 상품별 final_price 합계와 합계 금액 비교
- Sub-총상품수 기반 수량 보조 검증
