# Hanaro KB

이 디렉토리는 하나로마트 영수증 파싱을 위한 규칙 기반 Knowledge Base를 정의한다.

하나로마트는 상품 구조는 단순하지만,  
할인/합계/노이즈가 혼합되어 있어 가장 해석이 어려운 형태의 영수증이다.

---

# 기본 구조

하나로마트 영수증은 다음 흐름을 가진다:

상품명
→ 상품 상세 (code + unit_price + qty + total_price)
→ (선택) 상품 할인
→ (선택) 전역 할인
→ 합계

---

# 상품 구조

## item_name

상품명 라인

예:

001 P삼겹살  
007 P뒷다리(일반) /냉동 [3,800]  
COB P커피땅콩 헤이즐넛향 300.0g  

---

## item_detail

상품 상세 라인

기본 구조:

code + unit_price + qty + total_price

예:

8801045447001 2,180 1 2,180  
*265405 17,690 1 17,690  
002*2100051133899 2,000 2 4.000  

---

# 코드 규칙

- 6자리 ~ 13자리까지 다양
- 바코드 형태 존재
- 영문 prefix 포함 가능

예:

c8806163190310  
037600257640  

---

# 수량 규칙

- 기본적으로 qty 존재
- 일부 케이스에서 누락

예:

*230438 2,700 2,700  
→ qty = 1로 보정

## 정상 금액

2,180

## 할인 금액

# 할인 구조 (핵심)

하나로마트는 **두 가지 할인이 섞여 있음**

---

## 1. 상품 할인 (item discount)

상품 바로 아래 등장

예:

삼겹 한돈자조금 할인 -1.369  
005c99260200119192 -2.730 1 -2.730  

---

## 특징

- 직전 상품에 귀속
- 코드 포함 가능
- 영문 prefix 가능

---

## 2. 전역 할인 (receipt discount)

영수증 하단에 등장

예:

끝전할인: -4  
총할인액: -4  
쿠폰할인: -660  
농축산물 할인쿠폰 (4월2차) -1,400  

---

## 특징

- 특정 상품이 아닌 전체 할인
- item에 귀속하지 않음

---

# 중요한 문제: 중복 할인

하나로마트는 동일 금액이 중복 등장할 수 있음

예:

상품 할인 -1,400  
하단 총할인액 -1,400  

---

## 처리 규칙

- 동일 금액 중복 시 1회만 반영
- dedupe_policy 필요

---

# 정규화 포인트

## 대괄호 제거

[3,800], [카드쿠폰(율)] → 제거

예:

[카드쿠폰(율)]선진 삼겹 → 선진 삼겹  

---

## prefix 제거

- * 제거
- 상품번호 제거

---

## 영문 prefix

COB, c 등 제거 가능

---

## 숫자 정규화

- 4.000 → 4,000
- -1.369 → -1,369

---

## OCR 보정

끝 전할 인 → 끝전할인  

---

# 노이즈 라인

다음 라인은 제거 대상:

- 상품(코드) 단가 수량 금액
- 이벤트 할인 (설명 라인)
- 내부 코드 라인

---

# 합계 / 종료 라인

다음 라인은 item 파싱 종료 기준:

- 총구매액
- 내실금액
- 총할인액

---

# 파서 출력 예시

입력:

8801045447001 2,180 1 2,180  

출력:

{
  "line_type": "item_detail",
  "code": "8801045447001",
  "qty": 1,
  "unit_price_raw": 2180,
  "price_raw": 2180
}

---

# 핵심 요약

- 코드 길이 다양 (6~13자리)
- 할인 구조가 복합적
- item 할인 + receipt 할인 혼합
- 중복 할인 존재
- OCR 오류 빈번
- Parser는 구조만 추출하고 의미 해석은 하지 않는다

---

# 한 줄 정의

Hanaro는 할인과 합계 구조가 혼합된 복잡한 영수증이다.
