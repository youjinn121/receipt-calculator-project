# Costco KB

이 디렉토리는 Costco 영수증 파싱을 위한 규칙 기반 Knowledge Base를 정의한다.

Costco는 할인 구조와 금액 표기 방식이 명확하지만, 패턴이 다양하고 복잡한 편이다.

---

# 기본 구조

Costco 영수증은 다음 구조를 가진다:

상품명
→ 상품 상세 (code + qty + price)
→ (선택) 할인 블록
→ 다음 상품

---

# 상품 구조

## item_name

상품명 라인

예:
카스375MLX20캔
유기농 우유
정통어묵탕모듬

---

## item_detail

상품 상세 라인

기본 구조:

code + qty + unit_price + total_price

예:

672904 1x 25,490 25,490  
650635 2x 9,590 19,180  
502305 1 2990 2,990T  

---

# 수량 표기

Costco는 다양한 수량 표기를 사용한다:

- 1x
- 1X
- 1 (x 없음)

Parser에서는 모두 동일하게 처리해야 한다.

---

# 코드 규칙

- 일반 상품 코드: 6자리
- 일부 할인 코드: 4~5자리
- 확장: 최대 7자리

# 중요 규칙

## 1. 할인 연결 (Parser 금지)

Parser는 다음을 하지 않는다:

- 할인 → 상품 연결
- discount_target 처리
- final_price 계산

이 작업은 Semantic Interpreter에서 수행한다.

---

## 2. 할인 귀속 기본 규칙

- discount_target이 있으면 해당 상품에 귀속
- 없으면 직전 상품에 귀속

---

## 3. 동일 상품 반복

같은 상품이 여러 번 등장할 수 있다.

예:
백합조개 3회

조건:

- code 동일
- unit_price 동일
- discount 상태 동일

→ semantic 단계에서 그룹화 가능

  "price_raw": 9590
}

# 핵심 요약

- 구조는 명확하지만 패턴 변형이 많다
- 할인 구조가 존재 (CPN / IRC / EXM / PP)
- 금액 표기가 다양하다 (-, -T, T)
- Parser는 구조만 추출하고 의미 해석은 하지 않는다

---

# 한 줄 정의

Costco는 할인 블록 구조가 존재하는 고정형 + 변형 패턴 혼합 영수증이다.
