# Emart KB

## 1. 상품 상세 구조
- 13자리 바코드 기반 item_detail
- 상품 상세 라인: 바코드, 단가, 수량, 금액 중심

## 2. 주요 할인 표기
- 앱 할인
- 에누리
- 행사 할인
- 결제할인
- 카드할인
- 삼성카드할인

## 3. 상품 단위 할인 처리
- 상품 바로 아래 할인 라인을 discount_detail로 처리

## 4. 영수증 단위 할인 처리
- 결제할인, 카드할인 등은 receipt_discount로 분리

## 5. 최종 금액 기준
- 결제대상금액

## 6. Validation 활용
- 상품 final_price 합계와 결제대상금액 비교
